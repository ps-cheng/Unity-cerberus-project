# Cerberus 美術風格指南

所有場景、敵人、Boss、道具的生成都照這份指南。角色動畫的規則另外寫在 `D:\Codex\sprite-work\CLAUDE.md`。

## 共通風格描述

每一次生成都要把下面這段加進描述，畫面才會統一：

```
2D side-scrolling action game asset, hand-drawn cel-shaded style with thick black outlines and flat colors, matching the existing character art. Cyberpunk near-future city at night. Side view. No people, no readable text or letters (use abstract glyphs and symbols on signs). Nothing sexually explicit.
```

## 色彩

| 用途 | 顏色 | 參考色碼 |
|---|---|---|
| 夜空、遠景底色 | 深藍紫 | `#1B1A33` |
| 街道、建築暗部 | 暗灰藍 | `#2A2C38` |
| 街頭霓虹 | 粉紅、青藍 | `#FF3EA5`、`#2FF3FF` |
| 赫托斯重工 | 鍛造橘、槍鐵灰 | `#FF7A1A`、`#4A4E58` |
| 塔洛斯 | 青銅 | `#B07A3A` |
| 冥河硬幣 | 青綠微光 | `#6FE3C8` |

色碼是方向參考，不要求完全一致。重點是：街頭用粉紅和青藍，企業的東西用橘色和灰色，兩者一眼分得出來。

## 畫面層次（最重要的規則）

玩家要一眼分出「背景」和「能互動的東西」：

- **背景（遠景、中景）**：比角色暗、對比低、顏色淡一點，描邊可以細一些。
- **遊戲層（平台、敵人、Boss、道具）**：完整對比、粗黑描邊，跟角色一樣清楚。平台頂面要比背景亮。
- **近景**：放在角色前面的雜物，用很暗的剪影，只出現在畫面邊緣，不能擋住戰鬥。

## 內容規則

- **看板和招牌上不要有真的文字**：生圖模型寫中文常常寫錯。招牌用抽象符號，需要文字的地方（例如教學提示）在 Unity 裡另外疊字。
- **廣告主題**：義肢、人體改造、能量飲料、夜店剪影、企業宣傳。點到為止，不露骨。
- **方向**：所有角色、敵人、Boss 一律面向右，需要面向左時在 Unity 裡翻轉。

## 素材清單

照這個順序生成。**第 1 項是風格基準**，生成後當作後面所有項目的參考圖之一。每次呼叫的參考圖最多 5 張。

| # | 素材 | 規格與重點 |
|---|---|---|
| 1 | 中景：街道建築 | 橫向長圖，左右可以無縫接續。擁擠的建築立面、陽台、糾結的電線、霓虹招牌、全像廣告看板。天空部分用綠色 `#00ff00` 留空，之後去背。這張是風格基準。 |
| 2 | 遠景：城市天際線 | 橫向長圖，左右可接續。遠處的企業高樓，其中一棟頂端有發著橘光的赫托斯重工標誌。不需要透明。 |
| 3 | 近景：前景雜物 | 橫向長圖，綠色背景。很暗的管線、電線、招牌剪影，只在上緣和下緣，中間留空。 |
| 4 | 保管庫內部（Boss 房背景） | 冷硬、乾淨的企業金庫空間，金屬牆面、橘色警示燈、深處有一個展示櫃的位置。跟街道的髒亂形成對比。 |
| 5 | 地面平台：街道路面 | 綠色背景。一段橫向的人行道加路緣，左端、中段、右端分得清楚，中段可以重複接續，用來做 9-slice。 |
| 6 | 浮空平台 | 綠色背景，一張圖畫 2～3 種，彼此分開：帶橘黑警示條紋的鋼樑、鷹架踏板、可以站上去的大型招牌頂。每種都要有左端、中段、右端。 |
| 7 | 赫托斯重工標誌 | 綠色背景。鐵鎚、鐵砧、火焰組成的徽章，橘色加槍鐵灰，沒有文字。之後當作貼花用在敵人和場景上。 |
| 8 | 地面巡邏機器人 | 綠色背景，面向右。**用履帶或輪子移動，不要有腳**（避免需要走路動畫）。槍鐵灰機身、橘色條紋、身上有赫托斯標誌，一台會往前衝撞的近戰型。 |
| 9 | 飛行無人機 | 綠色背景，面向右。懸浮的保全無人機，赫托斯配色。機身上要看得到 1～4 個槍口（雷射發射前的倒數圈會畫在槍口上）。 |
| 10 | 塔洛斯完整圖 | 綠色背景，面向右。青銅色的大型軍事機器人，一手持刀、一手持盾，背後收著觸手，腳踝有一處發光的弱點。這張是 Boss 的造型基準。 |
| 11 | 塔洛斯零件圖 | 以第 10 項為參考，綠色背景上把零件分開排列、彼此留間隔：軀幹加頭、持刀手臂、持盾手臂、觸手一節、觸手末端的雷射發射口、兩條腿（腳踝弱點單獨一塊）。 |
| 12 | 冥河硬幣 | 綠色背景。古老的銀色或青銅硬幣，刻著擺渡人或冥界的圖案，帶淡淡的青綠光。 |
| 13 | 保管庫道具 | 綠色背景，分開排列：圓形或厚重的保管庫大門、玻璃展示櫃（裡面是空的，硬幣另外放）。 |
| 14 | 街道道具 | 綠色背景，分開排列：堆疊的貨箱、空白的霓虹招牌框（教學提示會在 Unity 裡疊字上去）、垃圾袋、路障。 |
